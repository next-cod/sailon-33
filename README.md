# Лендинг «Сейлон»

Одностраничный маркетинговый сайт для холодной аудитории. Проект собран на Next.js App Router, TypeScript и Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

Для проверки перед публикацией:

```bash
npm run lint
npm run typecheck
npm run build
```

## Структура

- `app/` — страница, метаданные, sitemap и robots.
- `components/sections/` — 16 независимых смысловых секций лендинга.
- `components/product/` — интерактивные продуктовые демонстрации.
- `content/site-content.ts` — тексты сценариев, FAQ и данные интерактивов.
- `config/links.ts` — все внешние ссылки и canonical URL в одном месте.
- `lib/analytics.ts` — точки подключения будущей аналитики.

## Что заменить перед публикацией

В `config/links.ts` нужно указать реальные URL регистрации, входа, контактов, поддержки, политики и условий, а также публичный домен. Сейчас там намеренно стоят единые placeholders.

Также нужно подтвердить точные границы нагрузки по тарифам и окончательную техническую формулировку о хранении/обработке данных. Avito и Instagram не показаны как действующие каналы.
